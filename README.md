# LabelLabs Frontend

Modern B2B e-commerce platform for barcode and RFID solutions.

## Quick Start

```bash
npm install
npm run dev
```

Visit http://localhost:3000

## Technology Stack

- **Frontend:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **State Management:** React Hooks + localStorage
- **Payment:** Razorpay
- **Hosting:** AWS Amplify

## Features

- Modern responsive design
- User authentication with JWT
- Product browsing and filtering
- Shopping cart management
- Secure checkout with Razorpay payment
- Order history and tracking
- GST-based business registration
- Professional company information pages
